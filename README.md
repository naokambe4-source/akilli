# Akıllı Creative — WordPress teması + yardımcı eklenti

- `akilli-creative/` — tema
- `akilli-core/` — yardımcı eklenti (içerik türleri, bloklar, formlar, SEO, demo kurulum)
- `dist/` — kurulabilir ZIP'ler (`./build.sh` ile yeniden üretilir)
- `docs/KURULUM.md` — Türkçe kurulum ve yönetim rehberi
- `tools/generate-demo-images.py` — demo görsel üretici
